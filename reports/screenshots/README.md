# Screenshots & Tool Reports Directory Guide

- `reports/screenshots/`: Save tool UI screenshots using `<tool>_<scenario>_<short-desc>.png` (e.g., `pgmustard_s01_plan.png`, `dbforge_s07_profiler.png`).
- `reports/tool_reports/`: Save exported HTML/TXT/PDF tool outputs using `<tool>_<scenario>_<timestamp>.<ext>`.
